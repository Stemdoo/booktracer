# Проверка воспроизводимости

Эта таблица предназначена для заполнения после фактического запуска на чистом окружении. Нельзя отмечать проверки как успешные, пока они не выполнены на компьютере студента или под наблюдением одногруппника.

| № | Проверка | Команда/действие | Фактический результат |
|---:|---|---|---|
| 1 | Установка зависимостей | `python -m pip install -r requirements.txt` | Заполнить после выполнения |
| 2 | Конфигурация без секретов в коде | Создать `.env` на основе `.env.example`, задать локальные значения | Заполнить после выполнения |
| 3 | Проверка проекта | `python manage.py check` | Заполнить после выполнения |
| 4 | Миграции | `python manage.py migrate` | Заполнить после выполнения |
| 5 | UI | Открыть `/` и `/admin/` | Заполнить после выполнения |
| 6 | Публичный GET API | Открыть `/api/books/` и `/api/genres/` | Заполнить после выполнения |
| 7 | Авторизованный GET/POST API | Проверить `/api/my-book-statuses/` в сессии пользователя | Заполнить после выполнения |
| 8 | Сохранение | Создать тестовую запись, перезапустить приложение и прочитать её снова | Заполнить после выполнения |
| 9 | Диагностика | Проверить одну описанную проблему и пройти шаги из `troubleshooting.md` | Заполнить после выполнения |

## Протокол чистого локального запуска

1. Получить свежую копию репозитория либо использовать отдельное новое виртуальное окружение.
2. Установить поддерживаемую версию Python.
3. Создать окружение и установить `requirements.txt`.
4. Скопировать `.env.example` в `.env`; секреты задавать локально и не добавлять в Git.
5. Выполнить `python manage.py check`, `python manage.py migrate`.
6. Загрузить `library_data.json` только если база пустая и fixture необходим.
7. Запустить `python manage.py runserver`.
8. Проверить UI, API, авторизацию и сохранение записи после перезапуска.
9. Записать фактические результаты, приложить скриншоты без секретов и исправить инструкцию, если возникли незадокументированные шаги.

**Статус на момент подготовки документации:** автоматическая независимая проверка чистого запуска не заявляется. Её должен выполнить пользователь и заполнить таблицу фактическими результатами.
